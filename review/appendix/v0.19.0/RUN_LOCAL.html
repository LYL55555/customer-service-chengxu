解压SOURCE_v0.19.0.zip，进入CHENGXU_Source_v0.19.0。Python 3.10以上，推荐macOS；首次准备依赖：

python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 scripts/load_current_demo.py
python3 app.py

若本机Python已安装requirements中的Pillow，也可直接用该Python执行后两行；本次干净源码解压核验使用本机已有依赖，不宣称全新机器零依赖。

打开http://127.0.0.1:8765/。新客户只填称呼；选六场景、放截图或输入聊天，必要时补一句背景，点击生成。截图先复核角色/文字/顺序再导入，已有信息不必重填；无聊天生日、报价无预算可以开始。

保存结果回放无需key：从“顾问与客户”选“0.19.0 保存结果回放 · 虚构顾问小林”，查看五案原文和历史失败。四组可复制，负重失败可看不可复制，标题明确保存回放。载入脚本可重复运行，不覆盖已有客户与草稿。旧scripts/load_saved_demo.py只载入0.16.3历史示例，不是本轮验证；正常工作不必载入任何示例。

真实生成：在源码根目录自行新建.env，按CONFIG_TEMPLATE.txt填写地址、模型和key；不要把key放页面/聊天或提交包。刷新配置或重启后台。未配置会明确提示；刚重启显示已配置尚未验证，指当前服务还未发请求，不为改状态自动发探针。DeepSeek官方beta工具输出本轮实测，其他兼容提供方尚未同版实测。正常服务无验收调用上限、不自动重试。

本机OCR需要macOS及Swift命令行工具；其他平台可用文字与保存结果。端口默认8765，可在本地.env设PORT。该工具不是生产CRM，没有真实库存/订单接口、账号登录、云同步或自动发送微信；所有外部核实由顾问实际执行。

源码排除密钥、全部.env、运行数据库、缓存和保密题目原件；首次运行自行建立data。当前源码、方法论、五案请求和演示均标0.19.0；原50及旧包另留历史，不改旧评分。
